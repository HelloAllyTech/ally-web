# Ally Web

A modern web interface for mental health professionals built with React and TypeScript.

## Quick Start

```bash
# Clone repository
git clone git@bitbucket.org:keyvaluesoftwaresystems/lifeline-ui.git
cd lifeline-ui

# Install dependencies
npm install

# Start development server
npm run dev
```
The application will be available at `http://localhost:8080`

## Core Features

- 💬 Integrated chat system
- 📅 Calendar management
- 📊 Analytics dashboard
- 📚 Learning resources
- ⚡ Stress management tools
- ⚙️ Customizable settings

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Shadcn/UI
- React Query
- Framer Motion

## Scripts

```bash
npm run dev      # Development server
npm run build    # Production build
npm run lint     # Code linting
```
